This repository is my personal space for learning, implementing, and mastering **DSA through problem solving**.

> 💡 **The goal isn't just to solve problems — it's to understand why a solution works, analyze its complexity, and build the ability to solve unfamiliar problems.**

# ⏱️ Complexity Matters

Every solution focuses on understanding:

```text
┌──────────────────────────────────────┐
│          TIME COMPLEXITY             │
├──────────────────────────────────────┤
│ O(1)        Constant                │
│ O(log n)    Logarithmic             │
│ O(n)        Linear                  │
│ O(n log n)  Linearithmic            │
│ O(n²)       Quadratic               │
│ O(2ⁿ)       Exponential             │
│ O(n!)       Factorial               │
└──────────────────────────────────────┘
```

> ⚡ **Rule:** Don't just ask *"Does it work?"*
> Ask *"Can it be faster?"*
